# Contribuir a QuestLang

¡Gracias por tu interés! QuestLang es un proyecto pequeño y divertido — no hace falta experiencia previa en compiladores para aportar.

## Formas fáciles de ayudar

- **Proponer una palabra clave nueva** — abre un issue con el nombre, qué haría, y a qué se traduciría en JS.
- **Reportar un bug** — si algo del transpilador no funciona como esperabas, cuéntanos el código que escribiste y qué pasó.
- **Mejorar la documentación** — ejemplos nuevos, traducciones, correcciones.
- **Compartir el proyecto** — una estrella o un post en redes ayuda tanto como una línea de código.

## Cómo mandar un cambio

1. Haz fork del repo
2. Crea una rama: `git checkout -b mi-cambio`
3. Edita `docs/index.html` (el transpilador vive en la función `transpile()`)
4. Prueba tu cambio abriendo el archivo en el navegador
5. Abre un Pull Request describiendo qué cambiaste y por qué
