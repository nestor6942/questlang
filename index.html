LV. 1 VARIABLES

Todo objeto que recoges en el juego es una variable. Los objetos permanentes (armas legendarias) no se pueden reemplazar; los objetos comunes sí.

equip maxHealth = 100   // legendario: no se puede reasignar (const)
spawn health = maxHealth  // objeto común: cambia con el juego (let)
LV. 2 MISIONES

Las funciones son misiones (quest). Al completarlas, entregan una recompensa con respawn — el equivalente a un return.

quest attack(damage) {
  health = health - damage
  shout("¡Recibiste " + damage + " de daño! HP: " + health)
  respawn health
}
LV. 3 DECISIONES Y GRINDEO

check es tu chequeo de condición (if); retreat es tu retirada táctica (else). grind repite mientras la condición aguante, y raid repite un número fijo de rondas.

check (health <= 0) {
  shout("Game over.")
} retreat {
  shout("¡Sigues en pie!")
}

raid turn from 1 to 5 {
  attack(10)
}
LV. 4 PERSONAJES

Un character es una clase. Sus habilidades se definen con ability en vez de quest (porque viven dentro de un personaje, no sueltas). Un personaje puede evolucionar de otro con evolvesFrom — herencia, pero con sabor a evolución Pokémon.

character Hero {
  ability constructor(name) {
    this.name = name
    this.hp = 100
  }
  ability attack(damage) {
    this.hp = this.hp - damage
    shout(this.name + " bajó a " + this.hp + " HP")
  }
}

character Mage evolvesFrom Hero {
  ability castSpell() {
    shout(this.name + " lanza una bola de fuego 🔥")
  }
}

spawn gandalf = new Mage("Gandalf")
gandalf.castSpell()
LV. 5 INVENTARIO

Las listas son tu inventario. Añade objetos con .loot() y descártalos con .drop() — el resto de JavaScript para arrays (.length, acceso por índice) funciona igual.

spawn inventory = ["espada", "escudo"]
inventory.loot("poción")
shout("Tienes " + inventory.length + " objetos")
inventory.drop()
LV. 6 MAZMORRAS Y ERRORES

Una dungeon es un bloque riesgoso: si algo sale mal adentro, no revienta tu partida — lo atrapa el catch, como un jefe final que te manda de vuelta al checkpoint.

dungeon {
  check (inventory.length == 0) {
    throw "¡Inventario vacío, no puedes entrar!"
  }
  shout("Entraste a la mazmorra sin problemas.")
} catch (boss) {
  shout("💀 Te atrapó el jefe: " + boss)
}
